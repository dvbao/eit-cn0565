## Caveats detected automatically

- Every session has a single rest frame: drift, carry-over and the noise floor are not measured in-session.
- 50 kHz: the per-drive gain fit reduces the reciprocity error no more than it reduces pure noise (ratio 0.59 vs null 5th percentile 0.54); fitted drive gains are not reliable.
- 80 kHz: the per-drive gain fit reduces the reciprocity error no more than it reduces pure noise (ratio 0.66 vs null 5th percentile 0.48); fitted drive gains are not reliable.
- No operator-confirmed trial windows for: 50 kHz, 80 kHz (task labels are cue-assumed).
- Voltage mode: drive current was not measured (relative changes cancel it only if it is constant).
- Task order identical in every group: recognition is confounded with position in the sequence.
- Reconstructions use a 2-D disk with equally spaced electrodes: they are projections, not facial anatomy.
